# かんたん予定追加（Google カレンダー用）

ボタン操作で Google カレンダーに予定を登録する Web アプリです。
Google Apps Script（GAS）で動くので、サーバーや API キーの準備は要りません。スマホのホーム画面に置いて使えます。

## 「エラー 400: policy_enforced」が出る場合（高度な保護機能プログラム）→ ログイン不要版

Google アカウントで **高度な保護機能プログラム（Advanced Protection）** を使っていると、カレンダーにアクセスする未審査のアプリはブロックされます（自作の Apps Script も対象です）。
その場合は **`no-login/` フォルダの版** を使ってください。

- アカウントへのアクセス許可を **一切求めません**（承認画面が出ません）
- 「追加」を押すと、内容を入れた状態で Google カレンダーの **予定作成画面** が開くので、**［保存］を押すだけ** で登録されます
- 破壊試験のように複数件ある場合は、「1. 開く」「2. 開く」と順に押します。`.ics` ファイルでまとめて保存し、パソコンの Google カレンダーの「設定 → インポート」で一度に取り込むこともできます
- 土日祝のバッジ表示、現場名の候補、カテゴリごとのカレンダー指定は、通常版と同じように使えます
- できないこと：通知時間の指定（カレンダー側の既定の通知になります）と、登録の取り消し（カレンダー側で削除してください）

### セットアップ（ログイン不要版）

1. <https://script.google.com/> で新しいプロジェクトを作ります
2. `コード.gs` を **`no-login/Code.gs`** の内容に置き換えます（画面を表示するだけの数行です）
3. 「ファイル ＋」→ HTML → 名前を `index` にして、**`no-login/index.html`** を貼り付けます
4. ⚙ プロジェクトの設定 →「`appsscript.json` を表示」をオンにして、**`no-login/appsscript.json`** を貼り付けます（`"oauthScopes": []` の部分で、権限を使わないことを宣言しています）
5. デプロイ → 新しいデプロイ → ウェブアプリ（次のユーザーとして実行：**自分**、アクセスできるユーザー：**全員**）
6. URL をスマホで開き、⚙ 設定タブでカレンダーを登録します
   - **カレンダーID** は、パソコンの Google カレンダーで、カレンダー名の「︙」→「設定と共有」→「カレンダーの統合」にあります（`xxxx@group.calendar.google.com`）。メインのカレンダーは Gmail アドレスです
   - 設定はその端末のブラウザに保存されます

> 中身は HTML ファイル1つだけなので、Apps Script を使わずに、GitHub Pages など普通の Web サーバーに置いても動きます。

## 通常版（Apps Script でカレンダーに直接登録）

## できること

| タブ | 内容 |
|---|---|
| **破壊試験** | 現場名と打設日を入れて **材齢7日・材齢28日** をタップすると、破壊日を自動で計算して終日予定として登録します。任意の日数（例：材齢14日）や、日付を直接指定した追加もできます。何件でも一度に登録できます。打設日も一緒に登録できます。 |
| **営業 / 修理** | 件名を入れて、日付（今日・明日・明後日）、開始時刻、所要時間（30分〜3時間・終日）をボタンで選んで登録します。 |
| **⚙ 設定** | タブ（カテゴリ）ごとに、どのカレンダーに登録するかを決めます。登録画面でその都度変えることもできます。 |

ほかにも次の機能があります。

- 登録前に、土曜・日曜・祝日に当たる日を色付きのバッジで知らせます（祝日は Google の「日本の祝日」カレンダーで判定）
- 登録直後に出る「取り消す」ボタンで、いま登録した予定をまとめて消せます
- 一度入力した現場名は候補として出てきます
- 予定ごとに通知を付けられます（破壊試験は前日17:00など、営業・修理は30分前など）

予定タイトルの例：
```
【7日破壊】○○ビル新築工事 2F床      … 終日 2026/11/7
【28日破壊】○○ビル新築工事 2F床     … 終日 2026/11/28
【営業】△△様 打合せ                 … 14:00〜16:00
```

## セットアップ（5分ほど）

1. <https://script.google.com/> を開き、**新しいプロジェクト** を作ります
2. 最初からある `コード.gs` の中身を、このフォルダの **`Code.gs`** の内容で置き換えます
3. 左の「ファイル ＋」→ **HTML** を選び、名前を `index` にして、**`index.html`** の内容を貼り付けます
4. （任意）⚙ プロジェクトの設定 →「`appsscript.json` マニフェスト ファイルをエディタで表示する」をオンにして、**`appsscript.json`** の内容を貼り付けます（タイムゾーンが Asia/Tokyo になります）
5. 右上の **デプロイ → 新しいデプロイ** → 種類で **ウェブアプリ** を選びます
   - 次のユーザーとして実行：**ウェブアプリにアクセスしているユーザー**
   - アクセスできるユーザー：**自分のみ**（社内の人にも使ってもらう場合は「組織内の全員」など）
6. 表示された URL を開き、Google アカウントのアクセス許可を承認します
7. スマホで URL を開き、「ホーム画面に追加」するとアプリのように使えます

> Code.gs や index.html を書き換えたら、**デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン** で更新してください。

## カスタマイズ

`Code.gs` の冒頭を書き換えます。

```js
const CATEGORIES = [
  { key: 'concrete', label: '破壊試験', type: 'concrete',    prefix: '' },
  { key: 'sales',    label: '営業',     type: 'appointment', prefix: '【営業】' },
  { key: 'repair',   label: '修理',     type: 'appointment', prefix: '【修理】' },
  // 例：タブを増やす
  // { key: 'inspect', label: '点検', type: 'appointment', prefix: '【点検】' },
];

const CONCRETE_AGES = [7, 28];   // 例：[3, 7, 28] にすると材齢3日のボタンも出ます
```

- `type: 'concrete'` … 打設日から破壊日を計算するフォーム
- `type: 'appointment'` … 日付・時刻・所要時間を選ぶフォーム
- 時刻ボタン（9:00〜16:00）や所要時間ボタンは、`index.html` の `TIMES` と `DURS` で変えられます

## 動作確認だけしたい場合

`index.html` をパソコンのブラウザで直接開くと、デモモード（カレンダーには登録しない）で画面を試せます。
